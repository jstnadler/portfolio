Case note

This page demonstrates a theme-rendered Shopify collection template: faceted filtering, a working sort control, and one reusable product-card snippet driving an entire grid, built natively in Liquid, CSS and JavaScript rather than through a page-builder app. Facet counts, active-filter chips, and the load-more pagination all read from a single client-side filter state, the same pattern used to keep a real collection grid fast without a full page reload. This is a static replica of teeccino.com/collections/all for demonstration purposes: it reproduces the real product-card anatomy and a subset of the real catalog using actual Teeccino packaging photography, but the prices, ratings, review counts and attribute-pill combinations shown are illustrative sample data, not a verified export of the live catalog or its allergen/ingredient facts.
